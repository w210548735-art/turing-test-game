# TURING? 玩家文案规范

> 版本：2026-07-26
> 核心原则：先让玩家看懂，再让玩家产生情绪。

## 1. 总体语气

TURING? 的核心气质是“克制的悬疑实验”，不是恐怖故事，也不是卖弄概念的
哲学问答。玩家面对的核心命题是：

> 当语言可以被模仿，我们凭什么相信屏幕另一端？

文案应围绕语言、停顿、犹豫、证词、身份与判断展开。一个页面最多保留一句
强叙事句，其余内容负责解释规则和推动操作。

## 2. 场景分层

| 场景 | 主语气 | 使用方式 |
| --- | --- | --- |
| 1v1 首页、匹配、判断 | 悬疑 70% + 哲思 30% | 提出疑问，强调语言可能伪装 |
| 回声档案、回放、结案 | 档案感 60% + 克制诗意 40% | 强调过去、证词、未署名身份 |
| 教学、计时、按钮 | 功能性 90% + 品牌感 10% | 明确告诉玩家下一步及操作后果 |
| 登录、账户、安全、举报 | 功能性 100% | 不用隐喻，不隐藏风险和结果 |
| 反馈、关注、支持、空状态 | 亲切 70% + 可爱 30% | 可用少量“喵”、语气词或颜文字 |
| ROOT 运营后台 | 专业、精确 | 只描述数据、时间范围与数据源 |

“理想化”只用于双方授权、共同留下回声等协作场景，不作为游戏主叙事。

## 3. 写作规则

1. 标题尽量控制在两行，每行 4–9 个汉字。
2. 一句话只承担一个任务：营造氛围，或解释规则，或提示操作。
3. 涉及时间、身份、隐私、授权、举报、注销和不可撤销操作时，必须直说。
4. 不把 AI 描写成邪恶或低等，也不暗示真人一定更温暖、更混乱。
5. 避免反复使用“观察、判断、揭晓”；同一页面相邻区域不得重复同义句。
6. “喵”、`ing` 和颜文字只用于低风险反馈，单个弹窗最多出现一次。
7. 英文眉题用于建立档案编号感，不承担玩家必须理解的信息。

## 4. 核心叙事锚点

- 1v1 首页：`语言会伪装，你相信谁？`
- 首页说明：停顿、措辞和犹豫都可能成为证词；玩家只有一次身份判断。
- 匹配：寻找“尚未署名的声音”，但状态与等待时间仍要直接展示。
- 聊天空状态：问题应让对方暴露记忆、偏好或犹豫；“答案重要，迟疑也重要”。
- 最终判断：`现在，你相信哪一种答案？`
- 回声入口：`过去已经沉默，证词还在。`
- 回声回放：语言已经留下，身份仍未署名。

## 5. 禁用表达

- 不使用无法验证的夸张承诺，如“绝对安全”“完全匿名”“一定是真人”。
- 不用时间长短暗示 AI 补位或真人到达。
- 不用“对象”指代匹配参与者；使用“另一端”“匿名玩家”或“对方”。
- 不把普通操作写成谜语，例如不能用“抹去存在”代替“永久注销账号”。
- 不在安全警告、错误信息或管理后台中加入颜文字。
