# Security Policy

## Supported version

安全修复只维护默认分支的最新版本。部署方应及时更新依赖、运行数据库迁移，
并在发布前完成备份与恢复验证。

## Reporting a vulnerability

请通过 GitHub 的私密漏洞报告功能联系维护者。不要在公开 Issue、讨论区、
提交信息或日志中发布漏洞利用细节、用户数据、服务器地址或任何凭据。

报告应包含受影响版本、复现条件、影响范围和建议修复方向，但必须使用脱敏
样本。维护者确认前请勿公开披露。

## Secret handling

生产 Secret 只能通过环境变量、容器 Secret 或受权限保护的文件注入。仓库
仅提供占位示例，任何真实密码、Token、邮箱授权码、私钥和数据库备份都不得
进入 Git。
